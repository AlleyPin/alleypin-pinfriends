# AlleyPin PinFriends 角色生圖 skill

讓 Codex、Claude Code 照設計稿畫出不走樣的 PinFriends（山豆、吐司、瑞比、水可、伊吉、波提、石子）。內容包含七隻角色的外型規格、色票、高矮比例，以及從設計稿轉出來的參考圖。

## 下載安裝

### 👉 [下載安裝包 alleypin-pinfriends.zip](https://github.com/AlleyPin/alleypin-pinfriends/releases/latest/download/alleypin-pinfriends.zip)

這個連結永遠指向最新版。下載後照 [安裝教學](安裝教學.md) 安裝。

⚠️ **不要用綠色的「Code → Download ZIP」**：那樣下載的資料夾會叫 `alleypin-pinfriends-main`，跟 skill 名稱不一致。請用上面的連結。

**Claude 網頁版、Claude App 的一般對話不適用**：它們自己不能生圖。（Claude App 的「Code」分頁就是 Claude Code，可以用。）

### 用 Claude Code 或 Codex？直接貼這句給它

> 幫我安裝這個 skill：`git clone https://github.com/AlleyPin/alleypin-pinfriends.git`。Codex 請 clone 到 `~/.agents/skills/alleypin-pinfriends`，Claude Code 請 clone 到 `~/.claude/skills/alleypin-pinfriends`。

之後要更新，跟它說「幫我 git pull 更新 alleypin-pinfriends skill」就好。
